闭包（Closure）是 JavaScript 中一个非常核心且强大的概念。简单来说，**闭包是函数与其词法作用域（定义时的环境）的组合**，即使函数在定义时的作用域已经执行完毕，它仍然能记住并访问该作用域中的变量。

---

### 核心机制

JavaScript 的函数在定义时，会产生一个“词法作用域”。当这个函数被作为返回值返回、或者作为参数传递到其他作用域时，它会携带一个“背包”，里面装着定义时所能访问到的所有变量。**这个“背包”就是闭包。**

---

### 经典举例：计数器

```javascript
function createCounter() {
  let count = 0;  // 这个变量在外部无法直接访问

  // 返回一个内部函数（闭包）
  return function() {
    count++;      // 这个内部函数“记住”了 count 变量
    return count;
  };
}

const counter1 = createCounter();
const counter2 = createCounter();

console.log(counter1()); // 输出: 1
console.log(counter1()); // 输出: 2
console.log(counter1()); // 输出: 3

console.log(counter2()); // 输出: 1 （独立的闭包，互不干扰）
```

**解释：**
- `createCounter` 执行时，局部变量 `count` 被创建。
- 返回的内部匿名函数被赋值给 `counter1`。
- 当 `createCounter` 执行完毕后，按理说 `count` 应该被销毁。但由于返回的函数仍然引用它，JavaScript 引擎会把这个 `count` 保存在闭包中。
- 每次调用 `counter1()`，它都访问并修改那个“存活”的 `count`，而不是重新初始化。

### 实际应用场景

#### 1. 私有变量（模拟私有属性）
```javascript
function Person(name) {
  // 私有变量
  let age = 0;

  return {
    setName: function(n) { name = n; },
    getName: function() { return name; },
    grow: function() { age++; },
    getAge: function() { return age; }
  };
}

const p1 = Person('Alice');
p1.grow();
p1.grow();
console.log(p1.getAge()); // 2
console.log(p1.age);      // undefined（无法直接访问私有变量）
```

#### 2. 一次性初始化（惰性加载）
```javascript
let once = function(fn) {
  let result;
  let called = false;
  return function() {
    if (!called) {
      result = fn();
      called = true;
    }
    return result;
  };
};

let init = once(() => {
  console.log('执行一次初始化...');
  return { data: 42 };
});

console.log(init()); // 执行一次初始化...
console.log(init()); // 第二次调用，不再执行，直接返回缓存结果
```

### 注意事项与陷阱

#### 循环中的闭包（经典面试题）
```javascript
// 错误示例：结果可能是 3,3,3
for (var i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i);
  }, 100);
}
```

**原因：** `var` 没有块级作用域，`i` 是全局的，三个闭包共享同一个 `i`，等到 setTimeout 执行时，`i` 已经变成了 3。

**解决方法（两种）：**
```javascript
// 方式1：使用 let（块级作用域）
for (let i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i); // 输出 0,1,2
  }, 100);
}

// 方式2：立即执行函数（IIFE）包裹，创建独立作用域
for (var i = 0; i < 3; i++) {
  (function(num) {
    setTimeout(function() {
      console.log(num); // 输出 0,1,2
    }, 100);
  })(i);
}
```

### 闭包的内存管理

**优点：** 闭包可以保持变量不被垃圾回收，方便实现状态持久化。

**缺点：** 如果闭包过度使用，或闭包引用了超大对象，可能导致内存泄漏。需要在不需要时主动释放引用（如 `counter = null`）或避免无必要的闭包。

---

### 总结

| 特征 | 说明 |
|------|------|
| **定义** | 函数 + 它定义时的词法作用域 |
| **核心** | 函数可以访问外部函数中的变量，即使外部函数已返回 |
| **用途** | 私有变量、回调函数、函数柯里化、模块模式 |
| **风险** | 内存占用、循环中的闭包陷阱 |

理解闭包，关键是理解 **“函数在哪里定义，它就能访问哪里的变量”**，而不在于函数在哪里被调用。
