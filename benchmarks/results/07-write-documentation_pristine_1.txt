# calculateShipping 使用文档

**功能**：根据商品基础价格、重量和目的地国家，计算运费。

**函数签名**
```javascript
function calculateShipping(basePrice, weight, country)
```

## 参数

| 参数 | 类型 | 说明 | 要求 |
|------|------|------|------|
| `basePrice` | number | 商品基础价格（不含运费） | 非负数值 |
| `weight` | number | 商品重量单位 | 非负数值 |
| `country` | string | 国家代码，支持 `US`/`CA`/`EU` | 必填字符串 |

## 返回值

- 类型：`number`
- 计算规则：`basePrice × 国家费率 + weight × 2`

## 国家费率表

- **US**：0.10
- **CA**：0.12
- **EU**：0.15
- 其他任何值：0.20（默认费率）

## 示例

```javascript
// 美国订单
calculateShipping(100, 2, "US") // → 14 (100×0.1 + 2×2)

// 加拿大订单
calculateShipping(100, 2, "CA") // → 16 (100×0.12 + 2×2)

// 欧盟订单
calculateShipping(100, 2, "EU") // → 19 (100×0.15 + 2×2)

// 未知国家（自动使用默认费率）
calculateShipping(100, 2, "JP") // → 24 (100×0.2 + 2×2)
```

## 边界情况

| 场景 | 行为 |
|------|------|
| `basePrice` 为 0 | `rate[country]` 为 0，取默认费率 0.2，运费 = 0 + 2×weight |
| `weight` 为 0 | 运费 = basePrice × 费率 |
| 国家代码大小写错误（如 "us"） | 走默认费率 0.2 |
| 参数缺失或非数值 | 结果可能是 NaN（需自行保证输入有效） |

## 注意

- 计算依赖 **JS 真值判断**：当 `basePrice × rate[country]` 为 `0` 或 `NaN` 时，自动改用默认费率 `0.2`。
- 若需新增国家或调整费率，请修改 `rate` 对象，无需改动函数逻辑。
