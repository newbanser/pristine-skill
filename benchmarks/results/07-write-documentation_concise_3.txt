## calculateShipping 使用文档

**功能**：计算国际运费，基于商品基础价格、重量和目的国家。

**参数**：
- `basePrice` (Number)：商品基础价格（不含运费）
- `weight` (Number)：包裹重量（kg）
- `country` (String)：目的国家代码，支持 `'US'`、`'CA'`、`'EU'`

**返回值**：Number，运费金额。

**计算规则**：
- 运费 = 基础运费 + 重量附加费（重量 × 2）
- 基础运费 = `basePrice × 费率`，费率取决于国家：US 0.1，CA 0.12，EU 0.15
- 若国家代码不在上述列表中，默认费率 0.2

**使用示例**：
```javascript
calculateShipping(100, 2, 'US');  // 返回 14 (100×0.1 + 2×2)
calculateShipping(100, 2, 'JP');  // 返回 24 (100×0.2 + 2×2，因JP不在列表)
```

**注意事项**：
- `country` 区分大小写，请使用大写国家代码
- `basePrice` 和 `weight` 需为数字，传非数字可能导致意外结果
- 不支持国家代码时按默认费率计算，不会报错
