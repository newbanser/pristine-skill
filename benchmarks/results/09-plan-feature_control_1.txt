我来为你制定一个完整的"导出 CSV"功能实施计划，涵盖从需求分析到上线的全流程。

---

## 一、需求分析与范围定义

### 1.1 核心需求
- **功能**：在报表页面上增加"导出 CSV"按钮
- **入口**：报表工具栏或操作区（与现有导出 Excel 功能并列）

### 1.2 业务规则
| 场景 | 规则 |
|------|------|
| 大数据量（≥10万行） | 后台导出，通过消息通知下载 |
| 小数据量（<10万行） | 前端即时导出 |
| 过滤/排序状态 | 导出内容需反映当前视图状态 |
| 字段选择 | 默认导出全部可见列，可选：全部列 |

### 1.3 边界条件
- CSV 文件大小限制：建议 50MB（防止内存溢出）
- 特殊字符处理：逗号、引号、换行符需要正确转义
- 编码格式：**UTF-8 with BOM**（确保 Excel 打开中文不乱码）

## 二、技术方案设计

### 2.1 架构决策
```mermaid
flowchart LR
    A[前端<BR/>React/Vue] -->|1. 发起导出请求| B[后端 API]
    B -->|2. 判断数据量| C{数据量判断}
    C -->| < 10万行| D[同步处理<br/>直接返回 CSV]
    C -->| >= 10万行| E[异步任务<br/>生成 CSV 文件]
    E --> F[存储文件<br/>MinIO/OSS]
    F --> G[返回下载链接]
    G --> H[前端轮询/推送<br/>通知用户下载]
```

### 2.2 接口设计
```
POST /api/reports/{reportId}/export/csv
Request: { 
  filters: {},        // 当前过滤条件
  sort: {},           // 当前排序规则
  fields: [],         // 需导出的字段列表（空 = 全部）
  pageSize: 50000     // 分批读取大小
}
Response (同步):
{ status: "success", data: "csv_blob", fileName: "report-2024-01.csv" }

Response (异步):
{ status: "accepted", jobId: "csv_job_12345", pollUrl: "/api/export/csv/12345" }
```

### 2.3 后端实现要点

```python
# 伪代码示例
def export_csv(report_id, conditions, fields):
    # 1. 校验权限
    check_permission(user, report_id, "export")
    
    # 2. 计算数据量
    total_rows = count_rows(report_id, conditions)
    
    # 3. 根据数据量决定同步或异步
    if total_rows < 100000:
        csv_data = generate_csv_sync(report_id, conditions, fields)
        return Response(csv_data, download=True)
    else:
        job_id = create_export_job(report_id, conditions, fields)
        async_task.delay(job_id, ...)
        return {"status": "accepted", "job_id": job_id}
```

## 八、验收标准（完整）

1. 【必须】导出数据与当前报表展示一致（包含过滤和排序）
2. 【必须】CSV 能被 Excel、Notepad++ 正确打开
3. 【必须】10 万行数据同步导出 <5 秒
4. 【必须】50 万行数据异步导出 <3 分钟
5. 【建议】导出过程中用户可取消
6. 【建议】导出记录可在后台查询（审计需求）
