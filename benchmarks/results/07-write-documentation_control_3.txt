# calculateShipping 函数使用文档

## 功能说明

计算国际运费。根据商品基础价格、重量和目的地国家/地区，返回最终运费金额。

## 函数签名

```javascript
function calculateShipping(basePrice, weight, country)
```

## 参数说明

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `basePrice` | number | 是 | 商品的基础价格（货币单位） |
| `weight` | number | 是 | 包裹重量（kg） |
| `country` | string | 是 | 目的地国家/地区代码（US / CA / EU） |

> **注意**：`basePrice` 和 `weight` 需为数字，`country` 需为字符串。若其他类型可能导致计算异常或返回 `NaN`。

## 返回值

- **类型**：`number`
- **说明**：运费总额（基础运费 + 重量附加费）

## 计算公式

1. **基础运费**：
   - 若 `country` 在 `{ US: 0.1, CA: 0.12, EU: 0.15 }` 中，则 = `basePrice * 对应费率`
   - 若 `country` 不在上述映射中，则 = `basePrice * 0.2`（默认费率 20%）

2. **重量附加费**：`weight * 2`

3. **总运费** = 基础运费 + 重量附加费

## 使用示例

```javascript
// 示例1：发往美国
calculateShipping(100, 5, 'US');
// 基础运费 = 100 * 0.1 = 10
// 附加费 = 5 * 2 = 10
// 返回 20

// 示例2：发往加拿大
calculateShipping(50, 2, 'CA');
// 基础运费 = 50 * 0.12 = 6
// 附加费 = 2 * 2 = 4
// 返回 10

// 示例3：发往欧盟
calculateShipping(200, 3, 'EU');
// 基础运费 = 200 * 0.15 = 30
// 附加费 = 3 * 2 = 6
// 返回 36

// 示例4：未指定的国家（如 'JP'）
calculateShipping(100, 4, 'JP');
// 基础运费 = 100 * 0.2 = 20
// 附加费 = 4 * 2 = 8
// 返回 28
```

## 费率对照表

| 国家/地区代码 | 基础运费费率 |
|---------------|--------------|
| US            | 10%          |
| CA            | 12%          |
| EU            | 15%          |
| 其他          | 20%          |

## 注意事项

1. **国家代码必须大写**：函数对 `country` 参数区分大小写，传入 `'us'` 或 `'Us'` 会被视为“其他”国家，采用 20% 默认费率。
2. **无输入校验**：函数不校验参数类型，请确保传入正确的数值和字符串。
3. **极端值**：若 `basePrice` 为 0，则基础运费为 0，最终运费仅为重量附加费。
4. **负数**：负数参数会导致负数运费，请按业务场景确保参数非负。

## 常见问题

**Q: 为什么我传了 'US' 但结果和预期不同？**
A: 请检查 `country` 是否为大写字母且没有额外空格。

**Q: 如何添加新的国家费率？**
A: 需修改函数内部 `rate` 对象。此文档版本不支持运行时动态添加。

**Q: 运费是否会四舍五入？**
A: 不会。函数返回原始计算结果，可能包含小数。如需四舍五入，请在调用方自行处理。
