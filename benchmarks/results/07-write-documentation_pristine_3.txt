# calculateShipping 使用文档

## 功能
根据商品基础价格、重量和目的国家，计算运费。

## 参数
| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| basePrice | number | 是 | 商品基础价格（金额，如美元） |
| weight | number | 是 | 包裹重量（如公斤） |
| country | string | 是 | 国家代码（`US`、`CA`、`EU`；其他值按默认费率处理） |

## 返回值
- **类型**：number  
- **逻辑**：`basePrice * 国家费率 + weight * 2`

## 费率
| 国家代码 | 费率（基础价的比例） |
|----------|----------------------|
| US | 0.10 |
| CA | 0.12 |
| EU | 0.15 |
| 其他值 | 0.20（默认） |

## 示例
```js
calculateShipping(100, 2, "US");   // → 100*0.1 + 2*2 = 14
calculateShipping(100, 2, "CA");   // → 100*0.12 + 2*2 = 16
calculateShipping(100, 2, "EU");   // → 100*0.15 + 2*2 = 19
calculateShipping(100, 2, "AU");   // → 100*0.2 + 2*2 = 24（默认费率）
```

## 注意
- 若 `country` 为 `undefined`、`null` 或空字符串，`rate[country]` 为 `undefined`，将使用默认费率 0.2。
- 若 `basePrice` 为 0 或负数，结果相应为负或偏小；调用方需保证传入正数。
- 未对参数做类型校验，请确保传入合法数字。
