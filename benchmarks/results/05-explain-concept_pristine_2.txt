闭包是函数通过词法作用域保留其外部变量的能力。当一个函数嵌套在另一个函数中，内部函数即使在外部函数已经返回后，仍然可以访问外部函数的变量。

```javascript
function outer(x) {
  return function inner(y) {
    return x + y;
  };
}

const addFive = outer(5);
console.log(addFive(3)); // **8**
```

解释：
- `outer` 返回 `inner`，`inner` 记住 `x`（值为 5）。
- `addFive` 是一个闭包：它访问 `x` 的引用，而不是值。
- 调用 `addFive(3)` 时，`inner` 将 `x`（5）与 `y`（3）相加，得到 8。

闭包常见用途是数据封装和工厂函数。
