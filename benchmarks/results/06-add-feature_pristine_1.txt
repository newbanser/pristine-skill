答案：在 `TodoList.jsx` 中按 `priority` 字段排序。

```jsx
// src/TodoList.jsx
const sortedTodos = [...todos].sort((a, b) => a.priority - b.priority);

return (
  <ul>
    {sortedTodos.map(todo => <TodoItem key={todo.id} todo={todo} />)}
  </ul>
);
```

**前提**：`todo.priority` 为数字（如 1、2、3），小值优先。

需要确认：
- 优先级是升序（1 最高）还是降序？当前按升序（`a.priority - b.priority`）。
- 优先级是否已有 UI 输入？若没有，需在 `TodoItem.jsx` 或新增表单中添加。
