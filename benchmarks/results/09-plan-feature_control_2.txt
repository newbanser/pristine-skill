**CSV 生成的常见坑：**
```python
# 以Python为例，处理公式注入和特殊字符
import csv
import io

def generate_csv(rows):
    output = io.StringIO()
    writer = csv.writer(output, quoting=csv.QUOTE_ALL)
    writer.writerows(rows)
    
    # 防Excel公式注入
    sanitized = []
    for row in rows:
        clean_row = []
        for cell in row:
            if isinstance(cell, str) and cell.startswith(('=', '+', '-', '@')):
                clean_row.append("'" + cell)  # 加前缀防注入
            else:
                clean_row.append(cell)
        sanitized.append(clean_row)
    
    return output.getvalue()
```

### 6. 重要风险规避

| 风险点 | 应对措施 |
|--------|----------|
| 内存溢出 | 使用游标/流式查询数据库，禁止全表加载 |
| Excel 打开乱码 | 输出 UTF-8 BOM 或者在内容前加 `\ufeff` |
| 大文件生成耗时过长 | 异步化 + 前端进度提醒 |
| 多次点击导致重复导出 | 添加节流防抖处理 |
| 数据权限泄露 | 导出前二次校验用户数据范围权限 |
