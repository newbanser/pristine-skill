答案：修改 `src/TodoList.jsx` 的排序逻辑，并新增 `src/utils.js` 的优先级权重函数。

1. **`src/utils.js`**：新增优先级权重函数
```js
// src/utils.js
export const PRIORITY = { LOW: 0, MEDIUM: 1, HIGH: 2 };

export function priorityWeight(todo) {
  return PRIORITY[todo.priority] ?? 0;
}
```

2. **`src/TodoList.jsx`**：改用 `priorityWeight` 排序
```jsx
import { priorityWeight } from './utils';

// 原：todos.sort((a, b) => a.createdAt - b.createdAt)
// 改：
todos.sort((a, b) => priorityWeight(b) - priorityWeight(a));
```
