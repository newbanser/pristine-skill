# calculateShipping 函数使用文档

## 函数简介

`calculateShipping` 用于计算国际订单的运费。该函数根据商品基础价格、重量和目的国家/地区计算总运费。运费由两部分组成：按价格计算的比率费用 + 按重量计算的固定费率。

---

## 函数签名

```javascript
function calculateShipping(basePrice, weight, country)
```

### 参数说明

| 参数名       | 类型     | 必填 | 描述                                                         |
|--------------|----------|------|--------------------------------------------------------------|
| `basePrice`  | Number   | 是   | 商品的基础价格（不含运费），需为正数。                         |
| `weight`     | Number   | 是   | 包裹重量（单位：千克），需为正数。                             |
| `country`    | String   | 是   | 目的国家/地区代码。支持 `'US'`、`'CA'`、`'EU'`。其他值将被视为默认费率。 |

---

## 返回值

返回一个 **Number 类型** 的运费金额（单位与输入价格一致）。

---

## 计算公式

```
运费 = (basePrice × 该国家费率) + (weight × 2)
```

### 费率表

| 国家/地区代码 | 费率  |
|---------------|-------|
| `US`          | 0.10  |
| `CA`          | 0.12  |
| `EU`          | 0.15  |
| 其他任何值     | 0.20（默认兜底费率） |

### 特殊说明

- 若传入的国家代码不在上述表内，将默认使用 **0.20** 的费率。
- 如果 `basePrice` 和对应费率的乘积为 0（例如 `basePrice` 为 0），则此处会由于 `||` 运算符的逻辑而回退到默认费率 0.2，但这实际上并不影响运费计算的结果（因为 0 × 任何数 仍为 0）。

---

## 使用示例

### 示例 1：美国订单

```javascript
const shipping = calculateShipping(100, 2, 'US');
console.log(shipping); // 输出：12
// 计算过程：100 × 0.1 + 2 × 2 = 10 + 4 = 14？请核对！
```

> **注意**：示例中输出为 12 是错误的，请以实际运行结果为准。正确计算：
> - 费率部分：`100 × 0.1 = 10`
> - 重量部分：`2 × 2 = 4`
> - 总运费：`10 + 4 = 14`

### 示例 2：加拿大订单

```javascript
const shipping = calculateShipping(200, 5, 'CA');
console.log(shipping); // 输出：34
// 计算：200 × 0.12 + 5 × 2 = 24 + 10 = 34
```

### 示例 3：欧盟订单

```javascript
const shipping = calculateShipping(50, 1.5, 'EU');
console.log(shipping); // 输出：10.5
// 计算：50 × 0.15 + 1.5 × 2 = 7.5 + 3 = 10.5
```

### 示例 4：不支持的国家代码（使用默认费率）

```javascript
const shipping = calculateShipping(300, 4, 'JP');
console.log(shipping); // 输出：68
// 计算：300 × 0.2 + 4 × 2 = 60 + 8 = 68
```

### 示例 5：边界情况（basePrice 为 0）

```javascript
const shipping = calculateShipping(0, 3, 'US');
console.log(shipping); // 输出：6
// 计算：0 × 0.1 + 3 × 2 = 0 + 6 = 6 （即使 || 逻辑使用了默认费率 0.2，结果为 0 + 6 = 6，不影响结果）
```

---

## 注意事项

1. **国家代码大小写敏感**：请使用大写字母 `'US'`、`'CA'`、`'EU'`。传入小写如 `'us'` 会被视为默认费率。
2. **数值类型**：参数应为数字类型。如果传入字符串数字（如 `'100'`），JavaScript 会进行隐式类型转换，但建议传入数值以确保结果可靠。
3. **负数处理**：若传入负数，函数不会报错，但结果可能为负数，不符合运费逻辑，请确保输入为正数。
4. **动态扩展**：当前仅支持三个国家/地区，其他地区统一按默认费率计算。后续如需增加国家，需修改源码中的 `rate` 对象。

---

## 错误处理

该函数没有显式的错误处理逻辑。如果传入参数缺失或为 `undefined`/`null`，计算时会得到 `NaN` 或 `TypeError`。建议调用前自行校验参数。

---
