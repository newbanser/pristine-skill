闭包（Closure）是 JavaScript 中一个核心且强大的概念。**简单来说，闭包就是“函数 + 它能够访问的外部作用域”的结合体。**

更精确地说：**当一个内部函数引用了外部函数的变量时，即使外部函数已经执行完毕，这个内部函数依然可以访问那些变量。这个内部函数连同它引用的变量环境，就构成了闭包。**

---

### 核心原理（作用域链）

JavaScript 中的函数作用域是嵌套的。内部函数可以访问外部函数的变量，是因为 JS 引擎在创建函数时，会形成一条 **作用域链**。闭包的本质就是：**内部函数保存了对外部函数变量的引用（不是拷贝），因此即使外部函数返回了，这些变量也不会被垃圾回收机制销毁。**

---

### 1. 基本示例（经典闭包）

```javascript
function createCounter() {
  let count = 0; // 外部函数的局部变量

  // 返回一个内部函数（这就是一个闭包）
  return function() {
    count++; // 内部函数引用了外部变量 count
    console.log(count);
  };
}

const counter = createCounter(); // 执行外部函数

counter(); // 输出: 1
counter(); // 输出: 2
counter(); // 输出: 3
```

**解释：**
- `createCounter` 执行后，理应被销毁，局部变量 `count` 应该被回收。
- 但因为它返回了内部函数，而内部函数持有了 `count` 的引用，所以 `count` 依然存活。
- 每次调用 `counter()`，它都能记住并修改上一次的 `count` 值。

---

### 2. 实际应用场景（防抖/节流）

闭包最常用的场景是**封装私有变量**和**保存状态**。下面用 HTML 按钮点击防抖（防止多次提交）来举例：

```html
<button id="submitBtn">点击提交</button>
```

```javascript
const btn = document.getElementById('submitBtn');

// 防抖函数（利用闭包保存定时器ID）
function debounce(fn, delay) {
  let timer = null; // 闭包变量，保存定时器状态

  // 返回的闭包函数
  return function() {
    // 如果已有定时器，则清除（相当于取消上一次的延迟执行）
    if (timer) clearTimeout(timer);
    // 重新设置定时器
    timer = setTimeout(() => {
      fn();
    }, delay);
  };
}

// 实际要执行的操作
function submitForm() {
  console.log('表单已提交！');
}

// 创建防抖处理函数（闭包实例）
const debouncedSubmit = debounce(submitForm, 1000);

// 绑定事件：快速点击多次，只会执行最后一次
btn.addEventListener('click', debouncedSubmit);
```

这里 `timer` 变量被闭包保存，每次点击都不会重新初始化，而是复用上一次的值，从而实现了“快速点击只触发一次”的效果。

### 3. 闭包与循环（经典陷阱与解决）

这是面试常考点：在循环中创建闭包，变量捕获的是**最终值**，而不是每次迭代的值。

```javascript
// ❌ 错误示例：输出 3, 3, 3
for (var i = 0; i < 3; i++) {
  setTimeout(() => {
    console.log(i); // 因为 i 是 var 声明的，循环结束后 i=3
  }, 1000);
}

// ✅ 正确示例 1：使用 let（ES6）
for (let j = 0; j < 3; j++) {
  setTimeout(() => {
    console.log(j); // 输出 0, 1, 2 （let 每次迭代生成了新的作用域）
  }, 1000);
}

// ✅ 正确示例 2：使用闭包手动捕获（老式写法）
for (var k = 0; k < 3; k++) {
  // 立即执行函数（IIFE）创建独立作用域
  (function(num) {
    setTimeout(() => {
      console.log(num); // 输出 0, 1, 2
    }, 1000);
  })(k);
}
```

### 4. 闭包模拟私有变量（模块化思想）

```javascript
function createPerson(name) {
  // 私有变量
  let age = 0;

  // 返回公共接口（也是一个闭包集合）
  return {
    getName: function() {
      return name;
    },
    getAge: function() {
      return age;
    },
    growUp: function() {
      age++; // 外部无法直接修改 age，只能通过这个方法
    }
  };
}

const person = createPerson('张三');
console.log(person.getName()); // 张三
person.growUp();
person.growUp();
console.log(person.getAge()); // 2
// 外部无法直接访问 person.age (undefined)
```

---

### 闭包的“代价”与注意事项

1. **内存占用**：闭包会使外部变量不被回收，如果滥用会造成内存泄漏。用完置 `null` 可释放。
2. **性能**：闭包比普通函数有额外的作用域查找开销。

---

### 总结

- 闭包 = **函数 + 词法作用域（外部变量的引用）**
- 它能让你在函数外部“记住”函数内部的变量。
- 它被广泛用于：数据私有化、函数柯里化、防抖节流、模块封装等。

理解闭包的关键是：**闭包“记住”的不是值，而是“变量本身”的引用**，因此后续修改是可以被看到的。
