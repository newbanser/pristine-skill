我来帮你重构这段代码。主要问题是重复的日期转换逻辑和补零操作，可以通过提取通用函数来消除重复：

```javascript
// 提取通用的补零函数
const padZero = (num) => String(num).padStart(2, '0');

// 提取通用的日期解析函数
const parseDate = (date) => new Date(date);

// 提取通用的日期格式化核心逻辑
const formatDateCore = (date, separator) => {
  const d = parseDate(date);
  return `${d.getFullYear()}${separator}${padZero(d.getMonth() + 1)}${separator}${padZero(d.getDate())}`;
};

// 各个具体格式化函数
const formatDate = (date) => formatDateCore(date, '-');
const formatDate2 = (date) => formatDateCore(date, '/');
const displayDate = (date) => {
  const d = parseDate(date);
  return `${d.getMonth() + 1}月${d.getDate()}日`;
};
```

如果希望更简洁，可以用箭头函数一行实现：

```javascript
const padZero = (num) => String(num).padStart(2, '0');
const parseDate = (date) => new Date(date);
const formatDateCore = (date, separator) => {
  const d = parseDate(date);
  return `${d.getFullYear()}${separator}${padZero(d.getMonth() + 1)}${separator}${padZero(d.getDate())}`;
};

const formatDate = (date) => formatDateCore(date, '-');
const formatDate2 = (date) => formatDateCore(date, '/');
const displayDate = (date) => {
  const d = parseDate(date);
  return `${d.getMonth() + 1}月${d.getDate()}日`;
};
```

如果希望更面向对象的方式，可以封装成一个类：

```javascript
class DateFormatter {
  constructor(date) {
    this.date = new Date(date);
  }
  
  padZero(num) {
    return String(num).padStart(2, '0');
  }
  
  formatWithSeparator(separator) {
    return `${this.date.getFullYear()}${separator}${this.padZero(this.date.getMonth() + 1)}${separator}${this.padZero(this.date.getDate())}`;
  }
  
  formatDash() {
    return this.formatWithSeparator('-');
  }
  
  formatSlash() {
    return this.formatWithSeparator('/');
  }
  
  formatChinese() {
    return `${this.date.getMonth() + 1}月${this.date.getDate()}日`;
  }
}

// 使用示例
const formatter = new DateFormatter('2024-01-15');
console.log(formatter.formatDash());    // "2024-01-15"
console.log(formatter.formatSlash());   // "2024/01/15"
console.log(formatter.formatChinese()); // "1月15日"
```

**推荐使用第一种方案**，因为它：
1. 保持了原有函数的调用方式不变，改动最小
2. 清晰易懂，保留了函数式编程风格
3. 消除了重复的日期解析和补零逻辑
4. 后续如果要添加新的日期格式，只需要复用 `formatDateCore` 函数即可
