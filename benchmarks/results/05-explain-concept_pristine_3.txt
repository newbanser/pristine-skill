闭包是函数记住并访问其词法作用域的能力，即使函数在其定义作用域之外执行。

```javascript
function createCounter() {
  let count = 0
  return function() {
    count++
    return count
  }
}

const counter = createCounter()
counter() // 1
counter() // 2
```

内层函数访问了外层函数的 `count` 变量，而 `count` 在 `createCounter` 执行后本应被回收，但闭包让它存活下来。

**核心机制**：
- 词法作用域在**定义时**确定，不在调用时
- 内部函数持有对外部变量引用的"背包"
- 每个闭包独立保留自己的变量副本

**实际用途**：
1. 数据私有化：模拟私有变量
2. 回调/事件处理器中捕获上下文
3. 函数工厂（如上例）
4. 记忆化（缓存函数结果）

**典型错误**：循环中创建闭包，变量被共享。
```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), i * 100)
}
// 3 3 3（var 无块级作用域）
```
用 `let` 声明 `i` 即可修复。
