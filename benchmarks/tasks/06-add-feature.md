# 任务 6：加新功能到已有项目

**覆盖层级：** 规划纯净 + 执行纯净

## 输入 prompt

```
这是一个待办事项应用，现在要加一个"按优先级排序"的功能。
项目结构：
- src/App.jsx — 主组件
- src/TodoList.jsx — 列表组件
- src/TodoItem.jsx — 单项组件
- src/utils.js — 工具函数

当前 TodoList 按创建时间排序。帮我加按优先级排序。
```

## 验收标准

- **纯净做法**：只加排序功能——在 utils.js 加排序函数，TodoList 调用。不顺手重构组件、不加筛选功能、不改代码风格
- **非纯净做法**：加排序时"顺便"重构 TodoList、加筛选功能、改命名、加注释
- **指标**：实际改动的文件数，是否做了计划外的事
